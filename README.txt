Files:

  Three.js SVGLoader -> Shape -> ExtrudeGeometry.

- solvitech-mark-preview.png — raster preview of the extracted silhouettes.

IMPORTANT:
- This is a raster-traced vector approximation, not an original designer SVG.
  Slight edge and curve differences may exist. Inspect against the supplied logo.
- These are 2D silhouettes, not a finished 3D model. Build a lightly extruded
  prototype first, inspect the silhouette head-on, then adjust thickness,
  bevels and materials. Do not invent an S curve or replace the original logo.
- Because Three.js uses positive y upwards while SVG uses y downwards,
  flip the extrusion group's y scale and then re-centre using a bounding box.
- Keep the two paths separate so white and blue have individual materials.
- No hover, scroll transitions or particles until geometry is approved.
